# 本地餐饮新媒体营销计划 — 实战模板

> 案例：老陕面馆（深圳宝安区）· 安康蒸面 · 宋老板
> 产出：8篇跨平台文案 + 4个HTML预览 + 11张可灵AI配图

---

## 一、项目背景

**客户**：老陕面馆，深圳宝安区一家主打安康蒸面的小店
**老板**：宋老板，从安康到深圳，带着家传配方
**核心产品**：安康蒸面——厚实软糯的蒸米皮，配芝麻酱+芥末+香料醋+豆芽
**差异化**：深圳少见的正宗安康蒸面，与凉皮有本质区别
**目标人群**：深圳打工人、陕西老乡、喜欢尝鲜的美食爱好者

## 二、营销策略

### 平台矩阵

| 平台 | 内容数 | 目的 | 调性 |
|------|:---:|------|------|
| 小红书 | 2篇 | 种草+探店导流 | 真实口语，大量Emoji |
| 公众号 | 2篇 | 深度品牌+科普 | 专业有人情味 |
| 视频号 | 2篇 | 私域裂变+情感连接 | 温暖走心 |
| 抖音 | 2篇 | 公域曝光+完播率 | 快节奏高能 |

### 内容角度分离（避免各平台重复）

1. **小红书①**：打工人早餐新选择 —— "深圳宝安的宝藏蒸面"
2. **小红书②**：夏天没胃口？这碗蒸面救我命 —— 开胃种草
3. **公众号①**：硬核科普 —— "安康蒸面到底是什么？和凉皮的区别"
4. **公众号②**：创始人故事 —— "二十年配方：从安康到深圳的坚守"
5. **视频号①**：创始人故事 —— "早上5点开始蒸面的人"
6. **视频号②**：顾客故事 —— "在深圳吃到老家味道"
7. **抖音①**：蒸面vs凉皮大对决 —— 视觉冲击对比
8. **抖音②**：蒸汽诱惑 —— 蒸笼开盖瞬间+芝麻酱淋面

## 三、执行流程

### Step 1: 信息采集（1次对话）

从运营方案文档提取：
- 店名、地址、营业时间
- 产品卖点（食材、工艺、口味）
- 品牌故事（创始人背景）
- 目标人群
- 旧文案（避免重复）

### Step 2: 分平台创作（并行）

每个平台用不同的角度切入，确保内容不重复：
- 检查运营方案中的"备用文案"段落
- 标记已用角度，换新角度创作

### Step 3: 可灵AI配图（批量）

```python
# 关键参数
model = "kling-v1-5"
aspect_ratio = "3:4"
n = 1
# 单批≤9张，每张间隔≥0.3秒
# 轮询每2秒/次，最多40次
```

配图分配：
- 小红书①：蒸面芝麻酱封面 + 筷子夹面
- 小红书②：配料全景 + 拌面动态 + 女生吃面
- 公众号①：淋芝麻酱封面 + 芝麻酱特写 + 香料醋熬制
- 公众号②：老板与蒸笼封面 + 蒸面出笼 + 芝麻现炒

### Step 4: HTML预览

每个平台做对应风格的HTML预览：
- 小红书：420px手机卡片，图片轮播，模拟评论区
- 公众号：680px文章布局，暖色调，分节标题

## 五、关键踩坑

1. **查重死角**：运营方案末尾的"备用文案"段落可能隐藏旧文案，需要全文对比
2. **可灵限流**：单批>9个任务触发429，必须加0.3秒间隔
3. **蒸面 vs 凉皮**：AI生成图容易把蒸面画成凉皮，提示词必须强调 `thick、wide strips、hearty`
4. **食物vs人像**：xhs-photographer-note 的人像提示词不适用于食物，必须用 food-kling-prompts
5. **角度分离**：每个平台必须用不同故事角度，避免8篇内容互相重复

## 六、复用指南

对下一个餐饮客户，按以下步骤复用：

1. **加载本技能 + restaurant-social-media + kling-prompt-library**

3. **提取关键信息**：店名、产品、故事、目标人群
4. **角度规划**：为4平台×2篇=8篇分配不同角度
5. **按 restaurant-social-media 技能分平台创作**
6. **批量跑可灵配图（kling-prompt-library 选图）**
7. **制作HTML预览交付客户**

预计工作量：2-3轮对话即可完成全部8篇 + 配图 + HTML预览。
